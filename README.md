# Bloomie
Bloomie on Pythonis loodav õpirakendus, kus iga õppeaine jaoks on oma lill virtuaalses aias. Rakendus aitab õpilastel ülesandeid kirja panna ja jälgida oma edusamme eri õppeainetes. Kui kasutaja teeb ülesandeid ära, kasvavad tema lilled ja hakkavad õitsema. Valisime selle projekti, sest see on kasulik, ilus ja aitab õppimist paremini korraldada.
