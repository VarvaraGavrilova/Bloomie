Bloomie on Pythonis loodav õpirakendus, kus iga õppeaine jaoks on oma lill virtuaalses aias. Rakendus aitab õpilastel ülesandeid kirja panna ja jälgida oma edusamme eri õppeainetes. Kui kasutaja teeb ülesandeid ära, kasvavad tema lilled ja hakkavad õitsema. Nii saab kasutaja kiiresti näha, millistele ainetele ta rohkem või vähem aega pühendab. Valisime selle projekti, sest see on kasulik, ilus ja aitab õppimist paremini korraldada.

Programmi käivitamine:
1. Laadi projekt GitHubist alla.
2. Ava fail main.py Thonnys.
3. Käivita programm (F5).
4. Vali menüüst sobiv tegevus ja järgi juhiseid.

Programmi kasutamiseks peavad failid main.py, tasks.py ja aed.py olema samas kaustas.
